# Sample Homepage Content — Assembly Demo

Ready-to-paste homepage copy for the Northstar corporate site and all nine studio brands. Widgets are called out in `inline code` so you can drop each block onto the right widget in the editor: `Hero`, `Layout`, `Rich Text`, `Image`, `Video`, `Callout`, `Key Takeaways`, `Table of Contents`, `Highlight`, `Links / Buttons`.

Copy is intentionally short, plain, and free of filler — it should read like a real studio wrote it.
